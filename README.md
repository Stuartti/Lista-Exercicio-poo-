# Lista de Exercícios - POO em Python 🐍

Este repositório contém a resolução de uma lista de exercícios práticos de **Orientação a Objetos (POO)** em Python, desenvolvidos aplicando o conceito de encapsulamento (`getters` e `setters`) e validados com testes automatizados utilizando o `pytest`.

---

## 📁 Estrutura do Projeto

* **`/codigo`**: Contém as classes desenvolvidas (como Pessoa, Produto, Funcionário, entre outras).
* **`/teste`**: Contém os arquivos de teste unitário criados para validar rigorosamente a lógica de negócio de cada classe.

## 🧪 Como Executar os Testes

Certifique-se de ter o Python e o `pytest` instalados na sua máquina. Na raiz do projeto, abra o terminal e execute:

```bash
pytest
